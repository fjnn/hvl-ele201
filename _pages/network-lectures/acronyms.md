## Common Networking Acronyms

| Acronym | Full Name | Short Description |
|---|---|---|
| <a id="lan"></a>**LAN** | Local Area Network | A network in a limited area, such as a room, office, or campus building. |
| <a id="wlan"></a>**WLAN** | Wireless Local Area Network | A LAN that uses wireless communication instead of cables. |
| <a id="wi-fi"></a>**Wi-Fi** | Wireless networking technology (IEEE 802.11) | Common wireless access technology used in homes, schools, and enterprises. |
| <a id="wan"></a>**WAN** | Wide Area Network | A network spanning larger geographic areas and interconnecting many LANs. |
| <a id="man"></a>**MAN** | Metropolitan Area Network | A network covering a city or large campus region. |
| <a id="pan"></a>**PAN** | Personal Area Network | Short-range network around one person (for example Bluetooth devices). |
| <a id="vlan"></a>**VLAN** | Virtual Local Area Network | Logical segmentation of a switched network into separate broadcast domains. |
| <a id="ssid"></a>**SSID** | Service Set Identifier | The network name of a Wi-Fi network. |
| <a id="bssid"></a>**BSSID** | Basic Service Set Identifier | MAC address that identifies a specific Wi-Fi access point radio. |
| <a id="ap"></a>**AP** | Access Point | Device that provides wireless clients access to a network. |
| <a id="nic"></a>**NIC** | Network Interface Card | Hardware interface that connects a device to a network. |
| <a id="mac"></a>**MAC** | Media Access Control | Layer 2 addressing method used in Ethernet and Wi-Fi frames. |
| <a id="ip"></a>**IP** | Internet Protocol | Layer 3 protocol for addressing and routing packets between networks. |
| <a id="ipv4"></a>**IPv4** | Internet Protocol version 4 | 32-bit IP addressing format (for example 192.168.1.10). |
| <a id="ipv6"></a>**IPv6** | Internet Protocol version 6 | 128-bit IP addressing format designed to replace IPv4. |
| <a id="icmp"></a>**ICMP** | Internet Control Message Protocol | Used for diagnostics and error reporting (for example ping replies). |
| <a id="arp"></a>**ARP** | Address Resolution Protocol | Resolves IPv4 addresses to MAC addresses in a local network. |
| <a id="dns"></a>**DNS** | Domain Name System | Resolves domain names (for example example.com) to IP addresses. |
| <a id="dhcp"></a>**DHCP** | Dynamic Host Configuration Protocol | Automatically assigns IP configuration to clients. |
| <a id="nat"></a>**NAT** | Network Address Translation | Translates private/internal IPs to public/external IPs. |
| <a id="tcp"></a>**TCP** | Transmission Control Protocol | Reliable, connection-oriented transport protocol. |
| <a id="udp"></a>**UDP** | User Datagram Protocol | Lightweight, connectionless transport protocol with low overhead. |
| <a id="http"></a>**HTTP** | Hypertext Transfer Protocol | Application-layer protocol used for web communication. |
| <a id="https"></a>**HTTPS** | Hypertext Transfer Protocol Secure | HTTP protected with TLS encryption. |
| <a id="tls"></a>**TLS** | Transport Layer Security | Cryptographic protocol securing communications over networks. |
| <a id="ssh"></a>**SSH** | Secure Shell | Secure remote login and command protocol. |
| <a id="ftp"></a>**FTP** | File Transfer Protocol | Legacy protocol for file transfer (not encrypted by default). |
| <a id="sftp"></a>**SFTP** | SSH File Transfer Protocol | Secure file transfer over SSH. |
| <a id="snmp"></a>**SNMP** | Simple Network Management Protocol | Protocol for monitoring and managing network devices. |
| <a id="ntp"></a>**NTP** | Network Time Protocol | Synchronizes time across networked devices. |
| <a id="vpn"></a>**VPN** | Virtual Private Network | Encrypted tunnel over another network (often the Internet). |
| <a id="poe"></a>**PoE** | Power over Ethernet | Delivers electrical power and data over the same Ethernet cable. |
| <a id="osi"></a>**OSI** | Open Systems Interconnection | Seven-layer reference model for network communication functions. |

## Notes

Some terms are strict acronyms, while others are abbreviations or protocol names commonly used the same way in networking practice.
